# Firmware update
1. Download and install nRF Device Firmware Update from playmarket
2. Download .zip package from release page of this repo
3. Start nRF Device Firmware Update
4. Select firmware .zip package<br>
5. Power on vario<br>
![img](images/select_file.jpg)
6. Select device. Device bluetooth name will be "Baklan Vario"<br>
![img](images/select_device.jpg)
7. Press and hold power button at vario **till the end of firmware update** and press "Start" button<br>
![img](images/start_update.jpg)
8. Wait for firmware update<br>

# Troubleshooting
Cannot find device: device powered off or doesnt have firmware. Try to power on device or press and hold power button and search for "BaklanDFU" device.
